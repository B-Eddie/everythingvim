    05 — Questions

    FAQ.

    Which sites does it work on?

    Pages, text fields, contenteditable, Google Docs, and supported code editors. Browser-internal pages and extension stores are restricted. Exclude sites in Options.

    How does the handoff avoid conflicts?

    Editing keys stay in the focused editor. A second Esc leaves a text field; Docs keeps focus.

    Why an overlay for code editors?

    Monaco, CodeMirror, and similar editors use a Vim buffer. Esc commits; Ctrl+C discards.

    Can I remap keys or exclude sites?

    Yes. Custom mappings and URL exclusions live in Options.
